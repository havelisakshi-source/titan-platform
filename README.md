# 🚀 TITAN Trading Platform

AI-powered NIFTY 50 stock screener with real-time BUY/SELL/HOLD signals.

## Features
- Scans all 50 NIFTY stocks
- Live price updates (SSE)
- BUY/SELL/HOLD with confidence scores
- Target & Stop Loss calculation
- Expected profit based on ₹1L capital
- Animated dashboard with dark/light mode

## Quick Start
```bash
pip install -r requirements.txt
python app/main.py
```
Open http://localhost:8000
